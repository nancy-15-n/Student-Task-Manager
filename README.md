# 📚 Student Task Manager

A responsive Task Manager web application built using HTML, CSS, and JavaScript. The application helps students organize, track, and manage daily tasks efficiently through an intuitive user interface.

## 🚀 Features

- ✅ Add new tasks
- ✅ Delete tasks
- ✅ Mark tasks as completed
- ✅ Filter tasks (All, Completed, Pending)
- ✅ Search tasks instantly
- ✅ Task priority levels (High, Medium, Low)
- ✅ Local Storage support
- ✅ Responsive design
- ✅ Dynamic DOM manipulation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## 🎯 How It Works

1. Enter a task.
2. Select task priority.
3. Click **Add Task**.
4. Search tasks using the search bar.
5. Filter tasks by status.
6. Mark tasks as completed.
7. Delete unnecessary tasks.
8. Tasks remain saved using browser Local Storage.
